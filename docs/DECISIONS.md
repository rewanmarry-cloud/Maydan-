## قيود معروفة
- Flutter وAndroid أولاً.
- العربية والفرنسية والإنجليزية.
- اللغة الافتراضية تتبع لغة النظام، مع اختيار يدوي محفوظ.
- الأرقام الغربية في اللغات الثلاث.
- الأولوية للحلول المجانية ومفتوحة المصدر؛ لا خدمة مدفوعة دون موافقة واضحة.

## القرار: Flutter وSQLite كبنية أساس offline-first
- التاريخ: 2026-11-03
- الحالة: معتمد
- القرار: Flutter 3.47.9، Dart 3.13.7، Provider، SharedPreferences وSQLite.
- السبب: ضروري لتشغيل الميزات الأساسية على Android دون خادم.
- التكلفة: الاعتمادات مجانية ومفتوحة المصدر؛ لا توجد خدمة مدفوعة.
- تأثير البيانات: SQLite محلي بملف `maydan.db` مع schema migration قابل للإضافة مستقبلاً.
- الاختبارات: تحليل Dart، 7 اختبارات widget/localization/navigation، وبناء APK.

## القرار: PDF عبر Printing وPDF packages
- التاريخ: 2026-11-03
- الحالة: معتمد
- القرار: إنشاء تقرير PDF داخلي ومشاركته عبر Android share flow.
- التكلفة: مجاني.
- القيود: لا يُستخدم CSV أو cloud storage حتى لا تضيف ميزات غير متحققة.
